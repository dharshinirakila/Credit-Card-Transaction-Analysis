Credit Card Transaction Analysis

Project Overview

This project focuses on analyzing credit card transaction data using SQL. The main objective is to understand transaction patterns, spending behavior, revenue distribution, and customer transaction activities.

Project Objectives

- Analyze total credit card transactions.
- Calculate total transaction amounts.
- Identify spending patterns.
- Analyze transaction categories.
- Understand customer transaction behavior.
- Identify high-value transactions.

Tools & Technologies

- SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

SQL Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- Aggregate Functions
- Joins
- Subqueries
- CTEs
- Window Functions
- CASE Statements

Business Questions

1. What is the total transaction amount?
2. What is the total number of transactions?
3. Which transaction category has the highest spending?
4. Which customers have the highest transaction amounts?
5. What is the average transaction value?
6. How do transactions vary over time?
7. Which categories contribute the most to total spending?

Key Insights

The analysis helps identify transaction trends, customer spending behavior, high-value transactions, and category-wise spending patterns.
